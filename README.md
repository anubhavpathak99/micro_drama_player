# Micro-Drama Interactive Player

A vertical, swipeable feed of short looping micro-drama episodes. Full-screen
Google Ad Manager test ads sit between episodes, and Episode 7 is behind a
paywall.

Android and iOS only: Google Mobile Ads does not support desktop or web.

## Run

Built with Flutter 3.47 (stable).

```sh
flutter pub get
flutter run
```

## Media credits

Episode videos stream from [Mixkit](https://mixkit.co) under the
[Mixkit License](https://mixkit.co/license/). The posters in `assets/posters/`
are each clip's first frame.
